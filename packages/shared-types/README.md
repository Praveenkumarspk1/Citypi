# Shared Types

Shared type definitions for AI Smart City Concierge, available in both Python and TypeScript.

## Installation

### TypeScript
```bash
npm install @concierge/shared-types
```

### Python
```bash
poetry add shared-types
```

## Usage

### TypeScript
```typescript
import type { User, Conversation, POI } from '@concierge/shared-types';
```

### Python
```python
from shared_types import Coordinates, Rating, Address
```
